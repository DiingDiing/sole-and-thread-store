# DIING LABEL — Fashion Storefront

**Tagline:** Wear your own way.

A responsive fashion storefront concept with a luxury editorial visual direction, which i built as a web-development demo project.

## Features
- Responsive desktop, tablet and mobile layouts
- Shoe and clothing category filters
- Live product search and sorting
- Add-to-bag cart with quantity controls, remove action and dynamic subtotal
- Product favourites
- Mobile navigation and slide-out cart drawer
- Newsletter form demo state
- Accessible labels and reduced-motion support

## Tech stack
HTML5 · CSS3 · Vanilla JavaScript · Google Fonts · Unsplash product photography

## Run locally
Open `index.html` in a browser. No build tools are required. For a local server, use the VS Code Live Server extension.


## Demo limitations
This is a front-end portfolio demo. Cart state is kept in the browser and is not saved to a database. Checkout, payment processing, user accounts, inventory management and newsletter delivery are not connected to a server.

GitHub Pages serves static files and does not execute PHP/Laravel. A production version can add Laravel, MySQL, authentication, admin product management, stock tracking, orders and a payment provider.

**Status:** Front-end demo complete; Laravel backend planned. The public-facing brand is DIING LABEL.

Product images are served by Unsplash, so an internet connection is required to load them.
